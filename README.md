# Shade Verse

Original-hero 3D rooftop swinging game built with React 18, Three.js, React Three Fiber, Framer Motion, GSAP, and WebGL2.

**Live:** https://shade-verse.vercel.app

## Local Development

```bash
npm install
npm run dev
```

## Checks & Build

```bash
npm run typecheck
npm run build
npm run preview
```
